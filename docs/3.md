## What is Machine Learning (ML)?

**Machine Learning (ML)** is a branch of Artificial Intelligence in which a computer system **learns patterns from data and uses those learned patterns to make predictions or decisions**, instead of being explicitly programmed with every rule.

### Traditional programming

In traditional programming:

```text
Rules + Data
    ↓
 Program
    ↓
Output
```

For example, to determine whether an email is spam, we might explicitly write rules:

```text
IF email contains "lottery"
    → Spam

IF email contains "winner"
    → Spam

IF email contains "free money"
    → Spam
```

The problem is that we cannot manually write rules for every possible situation.

---

### Machine Learning

With ML:

```text
Data + Expected Answers
          ↓
       ML Algorithm
          ↓
       ML Model
          ↓
      New Data
          ↓
      Prediction
```

For example, provide thousands of emails labeled:

```text
Email                         Label

"Win $1 million"              Spam
"Meeting at 3 PM"             Not Spam
"Claim your free prize"       Spam
"Project status report"       Not Spam
...
```

The ML algorithm learns patterns that distinguish spam from legitimate emails.

Then:

```text
"Congratulations! You won a prize"
                ↓
             ML Model
                ↓
              Spam
```

# 1. What is an ML Model?

An **ML model is a mathematical representation of patterns learned from training data**.

For example, suppose we want to predict house prices.

Our data might contain:

| Area (sq ft) | Bedrooms | Price |
| -----------: | -------: | ----: |
|          800 |        2 |  ₹40L |
|         1000 |        2 |  ₹50L |
|         1200 |        3 |  ₹65L |
|         1500 |        3 |  ₹80L |
|         2000 |        4 | ₹110L |

The model might learn something approximately like:

$
Price = w_1(Area) + w_2(Bedrooms) + b
$

Here:

* `Area` and `Bedrooms` → **features**
* `Price` → **target**
* ($w_1,w_2$) → **parameters/weights**
* (b) → **bias**
* Equation → **model**

During training, ML finds suitable values for the weights and bias.

---

# 2. What is Model Training?

**Training is the process of using data to find model parameters that minimize prediction error.**

A simplified training process is:

```text
          Training Data
                ↓
        Initialize Model
                ↓
          Make Prediction
                ↓
        Calculate Error
                ↓
        Calculate Gradient
                ↓
       Update Parameters
                ↓
          Repeat
                ↓
        Trained Model
```

For example:

$
Prediction = wx+b
$

Suppose:

```text
x = 10
Actual = 25
```

Initially:

```text
w = 1
b = 0
```

Prediction:

$
1(10)+0=10
$

Error:

$
25-10=15
$

The training algorithm adjusts `w` and `b`.

This process repeats many times until the model produces sufficiently accurate predictions.

# 4. Supervised Learning

In **supervised learning**, the training data contains both:

* Input
* Correct output/label

```text
Input X ──────────┐
                  ↓
              ML Model
                  ↓
Prediction ŷ
                  │
                  ↓
        Compare with actual y
                  │
                  ↓
                Loss
                  │
                  ↓
        Update model parameters
```

### Example

House-price prediction:

| Area | Bedrooms | Price |
| ---: | -------: | ----: |
|  800 |        2 |  ₹40L |
| 1000 |        2 |  ₹50L |
| 1500 |        3 |  ₹80L |

The model sees the correct prices during training.

After training:

```text
Input:
Area = 1300
Bedrooms = 3

        ↓

ML Model

        ↓

Predicted Price = ₹70L
```

### Common supervised-learning tasks

**Regression**

Predict a continuous number.

Examples:

* House price
* Temperature
* Sales
* Stock demand
* Delivery time

**Classification**

Predict a category.

Examples:

* Spam / Not Spam
* Fraud / Not Fraud
* Cat / Dog
* Disease category
* Customer churn / No churn

# 5. Unsupervised Learning

In **unsupervised learning**, we don't provide the correct answers.

We only provide data.

```text
Data
 ↓
ML Algorithm
 ↓
Discover Patterns
 ↓
Groups / Structure
```

For example:

```text
Customer data

Customer A → high spending
Customer B → low spending
Customer C → high spending
Customer D → medium spending
...
```

We don't tell the algorithm which customers belong together.

The algorithm discovers groups.

### Example: Customer segmentation

```text
             Customers
                 │
                 ↓
          Clustering Model
                 │
        ┌────────┼────────┐
        ↓        ↓        ↓
      Group 1  Group 2  Group 3
       High     Medium    Low
      Value     Value     Value
```

A common algorithm is **K-Means clustering**.

Other examples:

* Customer segmentation
* Anomaly detection
* Document clustering
* Dimensionality reduction

---

# 6. Semi-Supervised Learning

Sometimes we have:

```text
10,000 images

Only 1,000 labeled
9,000 unlabeled
```

Labeling all 10,000 images could be expensive.

Semi-supervised learning uses both:

```text
Labeled Data
      +
Unlabeled Data
      ↓
ML Model
```

For example:

```text
1000 labeled medical images
+
9000 unlabeled medical images
```

The labeled examples teach the model the desired task, while the unlabeled data can help it learn the underlying structure of the data.

This approach is useful when **labeled data is expensive but unlabeled data is abundant**.

---

# 7. Self-Supervised Learning

This is particularly important for modern AI and LLMs.

In self-supervised learning, the system creates a **training signal from the data itself**.

There is no human manually labeling every example.

### Example: predicting the next word

Consider:

```text
"The cat is sitting on the ___"
```

The model learns to predict:

```text
mat
```

The original text itself provides the training target.

```text
Text
 ↓
Create training task
 ↓
Predict missing/next information
 ↓
Calculate loss
 ↓
Update model
```

This is one of the fundamental ideas behind the pretraining of modern language models.

### Another example

Given:

```text
The capital of France is ___
```

The model learns to predict:

```text
Paris
```

from patterns in large amounts of text.

# 8. Reinforcement Learning

Reinforcement learning is different.

Instead of giving the model the correct answer for every input, we give an **agent an environment** and let it learn from **rewards and penalties**.

```text
             Environment
                  ↑
                  │
                Action
                  │
                  ↓
                Agent
                  │
                  ↑
                State
                  │
                  ↓
               Reward
```

For example, teaching an agent to play a game:

```text
Game State
    ↓
Agent
    ↓
Action
    ↓
Game
    ↓
Reward
    ↓
Learn
```

If the agent wins:

```text
+100 reward
```

If it loses:

```text
-100 reward
```

Over many attempts, the agent learns which actions tend to produce better outcomes.

Applications include:

* Robotics
* Game playing
* Resource optimization
* Autonomous systems
* Recommendation/ranking problems

# 9. Training, Validation and Test Data

Regardless of the learning approach, a very important ML concept is separating data.

A common setup is:

```text
                 Complete Dataset
                       │
              ┌────────┴────────┐
              ↓                 ↓
           Training            Test
             80%                20%
              │
              ↓
         Train Model
```

Often we further divide the training data:

```text
Complete Dataset
       │
       ├── Training      70%
       │
       ├── Validation    15%
       │
       └── Test          15%
```

### Training set

Used to **learn model parameters**.

### Validation set

Used to:

* tune hyperparameters
* compare models
* detect overfitting
* select the best configuration

### Test set

Used at the end to estimate how well the final model performs on **unseen data**.

# 10. Parameters vs Hyperparameters

This distinction is extremely important.

### Parameters

Learned by the model during training.

For linear regression:

$
y = wx+b
$

`w` and `b` are parameters.

The model learns them.

---

### Hyperparameters

Set by us before/during training.

Examples:

```text
Learning rate = 0.01
Number of epochs = 100
Number of trees = 100
Number of hidden layers = 3
Batch size = 32
```

The model doesn't automatically learn these in ordinary training; we choose or tune them.

---

# 11. What happens during training?

Let's take a simple neural network.

```text
Input
  ↓
Weights
  ↓
Prediction
  ↓
Loss
  ↓
Backpropagation
  ↓
Gradients
  ↓
Optimizer
  ↓
Updated Weights
  ↓
Repeat
```

For example:

$
y = wx+b
$

The model predicts:

$
\hat y
$

Then calculate loss:

$
L(y,\hat y)
$

The optimizer determines how the parameters should change:

$$
w_{new}
=
w_{old}
\eta
\frac{\partial L}{\partial w}
$$

where:

* (L) = loss
* (w) = parameter
* ($\eta$) = learning rate
* ($\frac{\partial L}{\partial w}$) = gradient

This connects directly to the **derivatives, gradients and optimization** topics you've been studying.

# 12. Batch, Mini-Batch and Online Training

Another way to classify training is by **how much data is used for each parameter update**.

### Batch Gradient Descent

Use the entire training dataset for one update.

```text
10,000 samples
      ↓
Prediction
      ↓
Loss
      ↓
Gradient
      ↓
Update
```

Advantages:

* stable gradient
* mathematically straightforward

Disadvantages:

* can be expensive for huge datasets

---

### Stochastic Gradient Descent

Use one training example at a time.

```text
Sample 1 → Update
Sample 2 → Update
Sample 3 → Update
...
```

It is faster per update but introduces more noise.

---

### Mini-Batch Training

Use a small batch.

For example:

```text
100,000 samples

Batch 1 → 64 samples
Batch 2 → 64 samples
Batch 3 → 64 samples
...
```

This is extremely common in modern ML and deep learning.

---

# 13. Epoch

An **epoch** means the model has processed the complete training dataset once.

Suppose:

```text
Training data = 10,000 samples
Batch size = 100
```

Then:

$$
\frac{10000}{100}=100
$$

So one epoch contains approximately **100 parameter-update steps**.

If we train for:

```text
20 epochs
```

the model processes the training dataset approximately 20 times.

# 14. Overfitting and Underfitting

This is one of the most important concepts in model training.

### Underfitting

The model is too simple.

```text
Training accuracy → Low
Test accuracy     → Low
```

The model hasn't learned the underlying pattern well enough.

---

### Good fit

```text
Training performance → Good
Test performance     → Good
```

The model generalizes well.

---

### Overfitting

The model learns the training data **too specifically**, including noise.

```text
Training accuracy → Very high
Test accuracy     → Poor
```

For example:

```text
Training = 99%
Test     = 72%
```

The model has memorized training patterns rather than learning patterns that generalize.

---

# 15. Regularization

Regularization is one technique used to reduce overfitting.

For example, in linear models we can add a penalty:

[
Loss =
PredictionError
+
\lambda \times Complexity
]

Common techniques include:

* L1 regularization
* L2 regularization
* Dropout
* Early stopping
* Data augmentation
