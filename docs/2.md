These terms are closely related, and understanding them is **fundamental to ML**. Let's use one practical example throughout: **predicting the price of a house**.

## 1. Input

**Input is the information that we give to a machine-learning model to make a prediction.**

Suppose we want to predict a house price.

We provide:

```text
Area        = 1500 sq.ft
Bedrooms    = 3
Bathrooms   = 2
Age         = 5 years
```

These values together are the **input**.

Mathematically:

$$
X =
\begin{bmatrix}
1500 & 3 & 2 & 5
\end{bmatrix}
$$

Think:

> **Input = everything the model receives.**

---

## 2. Feature

A **feature is an individual measurable property of the input that the model uses to make a prediction.**

In our example:

| Feature   | Value |
| --------- | ----: |
| Area      |  1500 |
| Bedrooms  |     3 |
| Bathrooms |     2 |
| Age       |     5 |

So:

```text
Input
 ├── Feature 1 → Area
 ├── Feature 2 → Bedrooms
 ├── Feature 3 → Bathrooms
 └── Feature 4 → Age
```

Therefore:

> **Feature = one piece of useful information used by the model.**

### Input vs Feature

This distinction is important:

```text
Input
   │
   ├── Feature 1
   ├── Feature 2
   ├── Feature 3
   └── Feature 4
```

The **collection of features** forms the input to the model.

---

# 3. Weight

A **weight tells the model how important a particular feature is when making a prediction.**

Suppose our model has learned:

$$
w_1 = 2000
$$

for Area,

$$
w_2 = 50000
$$

for Bedrooms,

and so on.

The model might calculate:

$$
y =
w_1x_1+w_2x_2+w_3x_3+w_4x_4
$$

For example:

$$
y =
2000(1500)
+
50000(3)
+
30000(2)
--------

10000(5)
$$

Here:

```text
x₁ → Area
w₁ → Area's weight

x₂ → Bedrooms
w₂ → Bedrooms' weight

x₃ → Bathrooms
w₃ → Bathrooms' weight

x₄ → Age
w₄ → Age's weight
```

The weight determines how strongly each feature influences the prediction.

### Important

**Weights are learned by the model during training.**

You generally don't manually decide them.

---

# 4. Bias

The **bias is an additional value that allows the model to shift its prediction independently of the input features.**

The basic equation is:

$$
\boxed{y=w_1x_1+w_2x_2+\cdots+w_nx_n+b}
$$

where:

* (x) = input/features
* (w) = weights
* (b) = bias
* (y) = prediction

For example:

$$
y=2x+5
$$

Here:

```text
2 → weight
5 → bias
x → input
y → prediction
```

If (x=10):

$$
y=2(10)+5=25
$$

Without the bias:

$$
y=2(10)=20
$$

The bias gives the model additional flexibility.

---

# 5. Parameters

This is where an important distinction comes in.

**Parameters are the values that the model learns during training.**

For a simple linear model:

$$
y=w_1x_1+w_2x_2+b
$$

the parameters are:

```text
w₁
w₂
b
```

So:

> **Weights + Biases = Model Parameters**

For example:

```text
Model

Feature 1 ──× w₁ ──┐
                   │
Feature 2 ──× w₂ ──┼──→ + Bias → Prediction
                   │
Feature 3 ──× w₃ ──┘
```

---

# Putting everything together

Consider a simple model that predicts salary based on experience.

Input:

$$
x=10
$$

Feature:

```text
Years of Experience = 10
```

Suppose the trained model has:

$$
w=5000
$$

and

$$
b=30000
$$

Then:

$$
Salary = wx+b
$$

$$
=5000(10)+30000
$$

$$
=80000
$$

So:

| Term                  | Example             |
| --------------------- | ------------------- |
| **Input**             | 10 years            |
| **Feature**           | Years of experience |
| **Weight**            | 5000                |
| **Bias**              | 30000               |
| **Parameter**         | 5000 and 30000      |
| **Output/Prediction** | 80000               |

---

# The most important concept: Training

Where do the weight and bias come from?

**Training.**

Initially, the model might have random values:

```text
weight = 1.2
bias   = -10
```

It makes a prediction.

Then it compares:

```text
Actual value
     ↓
Prediction
     ↓
Error
```

The optimization algorithm adjusts the parameters:

```text
weight
bias
  ↓
new values
  ↓
better prediction
```

This happens repeatedly.

Eventually:

```text
Training data
      ↓
   Model
      ↓
learns
      ↓
Weights + Bias
      ↓
Trained Model
```

This is one of the most important ideas in Machine Learning.

---

# Connection to Linear Algebra

Now you can see why we started with Linear Algebra.

Instead of writing:

$$
y=w_1x_1+w_2x_2+w_3x_3
$$

we can represent everything using vectors:

$$
\mathbf{x}=
\begin{bmatrix}
x_1\\
x_2\\
x_3
\end{bmatrix}
$$

and

$$
\mathbf{w}=
\begin{bmatrix}
w_1\\
w_2\\
w_3
\end{bmatrix}
$$

Then:

$$
\boxed{y=\mathbf{w}^T\mathbf{x}+b}
$$

This is the **dot product** we discussed earlier.

So the concepts connect like this:

```text
Features
   ↓
Input Vector
   ↓
      × Weights
   ↓
Dot Product
   ↓
   + Bias
   ↓
Prediction
```

And this simple equation:

$$
\boxed{y=\mathbf{w}^T\mathbf{x}+b}
$$

is the foundation of **Linear Regression, Logistic Regression, and the computation performed inside neural-network layers**.

### One-line memory trick

> **Input = what goes in, Features = what the input contains, Weights = how strongly features matter, Bias = adjustment, Parameters = values learned during training.**
