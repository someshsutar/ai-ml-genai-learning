# Learning Path: AI, ML & GenAI

## 1. **Foundations of AI & ML**
- **Mathematical foundations**: Linear algebra, probability, statistics, optimization.
- **Core ML concepts**: Supervised vs. unsupervised learning, regression, classification, clustering.
- **Algorithms**: Decision trees, k-NN, SVMs, ensemble methods (Random Forest, XGBoost).

---

## 2. **Deep Learning**
- **Neural networks**: Perceptrons, backpropagation, activation functions.
- **CNNs**: Image recognition, computer vision.
- **RNNs & LSTMs**: Sequential data, time series, NLP basics.
- **Transformers**: Attention mechanism, BERT, GPT.

---

## 3. **Generative AI (GenAI)**
- **Generative models**: GANs, VAEs.
- **Large Language Models**: GPT, LLaMA, Mistral — training, fine-tuning, prompting.
- **Diffusion models**: Image generation (e.g., Stable Diffusion).
- **Prompt engineering**: Techniques for effective interaction with LLMs.

---

## 4. **Applied AI & Tools**
- **LangChain & LangGraph**: Building agentic workflows.
- **Vector databases**: FAISS, Pinecone, Weaviate for RAG systems.
- **CopilotKit & React integration**: Embedding AI into applications.
- **Cloud AI platforms**: Azure AI, AWS SageMaker, Google Vertex AI.

---

## 5. **Advanced Topics**
- **Reinforcement learning**: Q-learning, policy gradients, RLHF.
- **Ethics & safety**: Bias, fairness, responsible AI.
- **Scaling AI systems**: Distributed training, model deployment, monitoring.

---

## 6. **Hands-On Projects**
- **Build ML models**: Kaggle datasets, scikit-learn.
- **Train a CNN**: Image classification with PyTorch/TensorFlow.
- **Fine-tune an LLM**: Domain-specific chatbot.
- **RAG system**: Retrieval-Augmented Generation with vector DB + LLM.
- **AI agent**: Appointment booking or workflow automation.
